# Project Memory

## Core
App "Sync" for unmarried male expats aged 25-40, aggregating events from Meetup.com, Eventbrite, and Lu.ma.
Match on activity history, not interest tags. Never expose outward-facing "interests" on user profiles.
Recurring events are first-class — surface "Nth time for you" and weekly series prominently to drive habit/retention.
Post-event flow: prompt user to tag 1-3 people they clicked with; mutual tags unlock DMs and form crews.
Visual identity uses a teal and coral color palette.
